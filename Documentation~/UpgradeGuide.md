# Convert existing AssetBundle code

To build your AssetBundles in an existing project with the Scriptable Build Pipeline (SBP) package, replace all calls to the [`BuildPipeline.BuildAssetBundles`](xref:UnityEditor.BuildPipeline.BuildAssetBundles) method with the [`CompatibilityBuildPipeline.BuildAssetBundles`](xref:UnityEditor.Build.Pipeline.CompatibilityBuildPipeline) method.

**Note**: Some features supported in `BuildPipeline` aren't available in the `CompatibilityBuildPipeline`.

## BuildPipeline and CompatibilityBuildPipeline features reference

The following table compares the features of the `BuildPipeline` with the `CompatibilityBuildPipeline`:

| Feature | `BuildPipeline` | `CompatibilityBuildPipeline` |
| :---- | :---- | :---- |
| Build AssetBundles | Call the `BuildPipeline.BuildAssetBundles` method. | Call the `CompatibilityBuildPipeline.BuildAssetBundles` method.  |
| Incremental building | Uses `IncrementalBuildHash` and `TypeTreeHash` to determine what to rebuild. For more information about incremental building with AssetBundles, refer to [Rebuilding assets incrementally](xref:um-asset-bundles-building). | SBP implements incremental building with the [`BuildCache`](xref:UnityEditor.Build.Pipeline.Utilities.BuildCache) class. |
| Asset loading path | AssetBundles built with BuildPipeline can load an asset with any of the following: <ul><li>Full path (`Assets/ExampleFolder/Asset.prefab`)</li><li>File name (`Asset`)</li><li>File name with extension (`Asset.prefab`)</li></ul> | AssetBundles built with SBP only support loading an asset by full path by default. For more information about how to load files by name instead of by full path, refer to [Load files by name](load-files-by-name.md). |
| AssetBundle manifest | The `BuildPipeline` accesses manifest information with the [`AssetBundleManifest`](xref:UnityEngine.AssetBundleManifest) class. | SBP accesses manifest file information with the [`CompatibilityAssetBundleManifest`](xref:UnityEngine.Build.Pipeline.CompatibilityAssetBundleManifest) class. This class has the same API as the [`AssetBundleManifest`](xref:UnityEngine.AssetBundleManifest) class, with an additional method to get the CRC value for a bundle. |
| AssetBundle .manifest files | Builds performed with `BuildPipeline.BuildAssetBundles` output YAML-format files with the .manifest file extension that describe the content of each AssetBundle. | SBP doesn't write .manifest files for individual AssetBundles. When `CompatibilityBuildPipeline` is used, SBP serializes the `CompatibilityAssetBundleManifest` object to a .manifest file with a name matching the build folder name. This file has similar, but not identical, content to the top level .manifest file that's generated by `BuildPipeline.BuildAssetBundles`. |
| Code stripping | Prevent Player builds from stripping out types that are only used in AssetBundles with [`BuildPlayerOptions.assetBundleManifestPath`](xref:UnityEditor.BuildPlayerOptions.assetBundleManifestPath) and the .manifest file generated by `BuildPipeline.BuildAssetBundles`. | SBP can generate a `link.xml` file to achieve the same result. Use `ContentPipeline.BuildAssetBundles` to make your own `BundleBuildParameters` and set [`WriteLinkXML`](xref:UnityEditor.Build.Pipeline.BuildParameters.WriteLinkXML) to `true`.|
| Build Report | The `BuildPipeline` generates a [`BuildReport`](xref:UnityEditor.Build.Reporting.BuildReport) file. | SBP doesn't generate a `BuildReport` file. |
| AssetBundle variants | Get AssetBundle variants with `AssetBundleManifest.GetAllAssetBundlesWithVariant`. | SBP doesn't support AssetBundle variants. |
| Build callbacks | Supports the following callbacks: <ul><li>`IPreprocessBuildWithContext`</li><li>`IPostprocessBuildWithContext`</li><li>`IProcessSceneWithReport`</li><li>`IPreprocessShaders`</li><li>`IPreprocessComputeShaders`</li></ul>  | Supports the following callbacks: <ul><li>`IProcessSceneWithReport` (including `[PostProcessScene]`)</li><li>`IPreprocessShaders`</li><li>`IPreprocessComputeShaders`</li></ul> **Note**: SBP doesn't invoke `IPreprocessBuildWithReport` and `IPostprocessBuildWithReport`.  |

## Build AssetBundles with options

Configure build options for the `CompatibilityBuildPipeline.BuildAssetBundles` method with [`BuildAssetBundleOptions`](xref:UnityEditor.BuildAssetBundleOptions).

### Options enabled by default

The `CompatibilityBuildPipeline.BuildAssetBundles` method enables the following options by default, and you can't disable them:

| Option | Notes |
| :---- | :---- |
| `DeterministicAssetBundle` | SBP builds deterministically. |
| [`DisableLoadAssetByFileName`](xref:UnityEditor.BuildAssetBundleOptions.DisableLoadAssetByFileName) | SBP only allows loading assets by full path, which is case-sensitive, and not by file name. For example, you must pass the exact full path `My/Example1/Example2/Asset.asset` to load the asset at that path, and not just `Asset` or `Asset.asset`. |
| [`DisableLoadAssetByFileNameWithExtension`](xref:UnityEditor.BuildAssetBundleOptions.DisableLoadAssetByFileNameWithExtension) | SBP only allows loading assets by full path, and not by file name plus extension. |

### Supported options

The `CompatibilityBuildPipeline.BuildAssetBundles` method supports the following `BuildAssetBundleOptions`:

| Option | Notes |
| :---- | :---- |
| [`UncompressedAssetBundle`](xref:UnityEditor.BuildAssetBundleOptions.UncompressedAssetBundle) | Identical to using [`BuildCompression.Uncompressed`](xref:UnityEngine.BuildCompression.Uncompressed). |
| [`DisableWriteTypeTree`](xref:UnityEditor.BuildAssetBundleOptions.DisableWriteTypeTree) | Identical to using [`ContentBuildFlags.DisableWriteTypeTree`](xref:UnityEditor.Build.Content.ContentBuildFlags.DisableWriteTypeTree). |
| [`ForceRebuildAssetBundle`](xref:UnityEditor.BuildAssetBundleOptions.ForceRebuildAssetBundle) | Identical to using [`IBuildParameters.UseCache = false;`](xref:UnityEditor.Build.Pipeline.Interfaces.IBuildParameters.UseCache). |
| [`AppendHashToAssetBundleName`](xref:UnityEditor.BuildAssetBundleOptions.AppendHashToAssetBundleName) | Identical to using [`IBundleBuildParameters.AppendHash = true;`](xref:UnityEditor.Build.Pipeline.Interfaces.IBundleBuildParameters.AppendHash). |
| [`ChunkBasedCompression`](xref:UnityEditor.BuildAssetBundleOptions.ChunkBasedCompression) | Identical to using [`BuildCompression.LZ4`](xref:UnityEngine.BuildCompression.LZ4). <br>**Note**: This has always been LZ4HC in the Editor, and LZ4 if it was recompressed at Runtime. |
| [`RecurseDependencies`](xref:UnityEditor.BuildAssetBundleOptions.RecurseDependencies) | Sets [`NonRecursiveDependencies = false`](xref:UnityEditor.Build.Pipeline.Interfaces.IBuildParameters.NonRecursiveDependencies) in `CompatibilityBuildPipeline`. |

The `CompatibilityBuildPipeline.BuildAssetBundles` method supports the following options, but they're not automatically converted. Use the proposed alternative to apply the corresponding build options:

| Option | Notes |
| :---- | :---- |
| [`AssetBundleStripUnityVersion`](xref:UnityEditor.BuildAssetBundleOptions.AssetBundleStripUnityVersion) | Use the `IBuildParameters` with [`ContentBuildFlags.StripUnityVersion`](xref:UnityEditor.Build.Content.ContentBuildFlags.StripUnityVersion) instead. |
| [`SuppressLoadableErrors`](xref:UnityEditor.BuildAssetBundleOptions.SuppressLoadableErrors) | Use the `IBuildParameters` with [`ContentBuildFlags.SuppressLoadableErrors`](xref:UnityEditor.Build.Content.ContentBuildFlags.SuppressLoadableErrors) instead. |

### Unsupported options

The `CompatibilityBuildPipeline.BuildAssetBundles` method doesn’t support the following `BuildAssetBundleOptions`:

* [`IgnoreTypeTreeChanges`](xref:UnityEditor.BuildAssetBundleOptions.IgnoreTypeTreeChanges)
* [`StrictMode`](xref:UnityEditor.BuildAssetBundleOptions.StrictMode)
* [`DryRunBuild`](xref:UnityEditor.BuildAssetBundleOptions.DryRunBuild)
* [`UseContentHash`](xref:UnityEditor.BuildAssetBundleOptions.UseContentHash)
* [`StripUnatlasedSpriteCopies`](xref:UnityEditor.BuildAssetBundleOptions.StripUnatlasedSpriteCopies)
