# Install Scriptable Build Pipeline

Requires Unity 6000.0 or later.

To install this package, do the following:

1. Open the **Package Manager** window (menu: **Window** > **Package Management** > **Package Manager**).
2. In the **Unity Registry**, search for `Scriptable Build Pipeline` or [install the package by name](xref:um-upm-ui-quick) (`com.unity.scriptablebuildpipeline`) to install the package.
